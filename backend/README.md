
# CyberSec Hack Lab — Backend

Node/Express API that powers the simulated challenges. **Demo only** (no real exploitation).

## Run locally

```bash
cd backend
npm install
npm run start
```

The server runs at `http://localhost:5000`.

## Endpoints

- `POST /api/xss` — Simulated XSS detection.
- `GET  /api/logs` — Returns demo logs and score.
- Placeholder: `/api/sqli`, `/api/login`, `/api/password`.
