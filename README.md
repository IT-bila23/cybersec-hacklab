
# CyberSec Hack Lab (Starter)

A portfolio-ready, **safe simulation** of common cybersecurity challenges with a modern dashboard.

## Stack
- Frontend: React (Vite) + Tailwind + Axios + Chart.js
- Backend: Node.js + Express
- NOTE: Everything is simulated for learning/demo purposes only.

## Quickstart

### 1) Backend
```bash
cd backend
npm install
npm run start
```
Server at http://localhost:5000

### 2) Frontend
```bash
cd frontend
npm install
npm run dev
```
App at http://localhost:3000

## What’s included
- XSS Challenge: working end-to-end with scoring and logs
- Dashboard: live logs and bar chart of attempts
- Placeholder endpoints/pages for SQLi, Login Exploit, Password Strength, Network Map

## Deployment (free)
- Frontend: Netlify / Vercel
- Backend: Render / Railway
